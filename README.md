## 🚀 Projeto em destaque

### 🤖 Bemobi Service Desk Bot

O **Bemobi Service Desk Bot** é um bot interativo desenvolvido em Python para simular um atendimento de suporte técnico de nível 1.

A aplicação funciona no terminal e oferece um menu interativo com opções para:

- Testar a conectividade com a internet;
- Simular uma solicitação de redefinição de senha;
- Solicitar acesso a sistemas;
- Escalar chamados para atendimento humano;
- Gerar tickets com número, data, prioridade e status;
- Exibir mensagens coloridas e animações no terminal.

🔗 **Acessar o repositório:**

[github.com/gabrielgomes-TI/Bemobi_service_desk_bot](https://github.com/gabrielgomes-TI/Bemobi_service_desk_bot)

---

## 🧩 Funcionalidades identificadas

- Menu interativo no terminal;
- Identificação do usuário;
- Teste de conexão utilizando o comando `ping`;
- Compatibilidade com Windows, Linux e macOS;
- Simulação de redefinição de senha;
- Solicitação de acesso a sistemas;
- Escalonamento para atendimento humano;
- Geração de chamados com identificador aleatório;
- Registro de data e hora;
- Definição de prioridade do chamado;
- Animações de carregamento;
- Utilização de cores ANSI;
- Validação de opções do menu;
- Encerramento da sessão pelo usuário.

## 🏁 Como executar o projeto localmente

### 1. Clone o repositório

```bash
git clone https://github.com/gabrielgomes-TI/Bemobi_service_desk_bot.git
```

### 2. Acesse a pasta do projeto

```bash
cd Bemobi_service_desk_bot
```

### 3. Verifique a instalação do Python

No Windows:

```bash
python --version
```

No Linux ou macOS:

```bash
python3 --version
```

### 4. Instale as dependências

O projeto utiliza apenas bibliotecas nativas do Python. Portanto, não é necessário instalar dependências externas com `pip`.

As bibliotecas utilizadas são:

- `os`;
- `platform`;
- `random`;
- `sys`;
- `time`;
- `datetime`.

### 5. Execute o bot

No Windows:

```bash
python Marin.py
```

No Linux ou macOS:

```bash
python3 Marin.py
```
